# Acceptance Criteria

**Version:** 1.0 Draft  
**Last reviewed:** 12 November 2026

---

## 1. Purpose

Define the criteria that the system must meet for each calculation type and functional area.

---

## 2. Criteria

### 2.1 Geometry & Units
- Areas, lengths, volumes, and counts verified with independent source or math.
- Units converted correctly (mm ↔ m ↔ cm).

### 2.2 Openings & Deductions
- Deductions applied and verified; no negative areas.

### 2.3 Calculation
- Gross, Net, Waste, Bulk rules follow the document.
- Determinism: same input = same output.

### 2.4 Verification
- Independent verification flags discrepancies.

### 2.5 BOQ
- Unique item codes; totals match; internal vs. client versions differ as allowed.

### 2.6 Testing & Backup
- Backup restores; sync conflicts resolved with decision log.
