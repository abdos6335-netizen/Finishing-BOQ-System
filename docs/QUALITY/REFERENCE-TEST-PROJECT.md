**Version:** 1.0 Draft  
**Last reviewed:** 12 November 2026

## 1. Purpose

Kitchen + Laundry is the first reference project for testing the system. Scope: **kitchen and laundry only**.

## 2. Scope

- Room boundaries from the drawing (or synthetic data).
- Floor, walls, ceiling quantities.
- Variations and openings.
- Materials and related items.
- BOQ and verification.

## 3. Data

Where the drawing is not a reliable reference, we use **synthetic explicit data**.

| Item | Value |
|------|-------|
| Room | Kitchen + Laundry |
| Floor area | 12 m² (kitchen) + 8 m² (laundry), synthetic |
| Wall height | 2.8 m |
| Door | 2.0 × 0.9 m |
| Variation | 1.5 m² (synthetic) |
| Materials | Synthetic unit data marked as such |
